# “基础 CSS 理解”评分指南

以下指南说明 MDN 学习区 CSS 主题——[基础 CSS 理解](https://developer.mozilla.org/zh-CN/docs/Learn/CSS/Building_blocks/Fundamental_CSS_comprehension)——的评分标准。下面列出了测验中的每项任务，并说明每项任务的分值和评分细则。

注意：这些内容是指导原则，并非一成不变的规则。遇到边界情况或标准不明确的情况时，可以根据实际情况自行判断分数。

总分为 35 分。请计算最终得分，然后除以 35，再乘以 100，得到百分制成绩。作为参考，可以查看[完成后的名片](index.html)，该答案应当获得满分。

## 基础设置

<dl>
<dt>“在与 HTML 和图片文件相同的目录中新建一个文件”（1 分）</dt>
<dd>第一项任务——创建你的 CSS 文件——只值 1 分。这一步很简单，但如果做不对，后面就什么都无法完成。</dd>
<dt>“通过 <code>&lt;link&gt;</code> 元素把你的 CSS 链接到 HTML 文件”（2 分）</dt>
<dd>稍有挑战性，但同样很简单。</dd>
<dt>“把它们复制并粘贴到新 CSS 文件的顶部。把它们当作测试，确保你的 CSS 已正确应用到 HTML 上。”（1 分）</dt>
<dd>这一项只是复制粘贴，因此占分不多。</dd>
<dt>“在这两条规则上方，添加一条 CSS 注释，写上一些文字，表明这是一组应用于整个页面的通用样式。写‘通用页面样式’即可。另外再添加三条注释……”（2 分）</dt>
<dd>良好的注释习惯很重要。只要四条注释写在合理的位置并且文字有意义，每条注释可得 0.5 分。</dd>
</dl>

## 你需要编写的新规则集

<dl>
<dt>“编写一个同时作用于卡片页眉和卡片页脚的规则集……”（3 分）</dt>
<dd>正确的规则应<a href="style.css">类似这样</a>。由于 <code>&lt;html&gt;</code> 元素上设置的默认字号是 10px，因此 1em 等于 10px，高度（30px）应写作 3em，内边距应写作 1em。10 + 30 + 10 = 50。</dd>
<dt>“浏览器对 <code>&lt;h2&gt;</code> 和 <code>&lt;p&gt;</code> 元素应用的默认外边距会干扰我们的设计”（3 分）</dt>
<dd>正确的规则应<a href="style.css">类似这样</a>。只需把所有段落和 <code>&lt;h2&gt;</code> 的外边距设为 0 即可。</dd>
<dt>“为防止图片溢出名片主体内容（<code>&lt;article&gt;</code> 元素），我们需要给它指定一个特定的高度。”（3 分）</dt>
<dd>正确的规则应<a href="style.css">类似这样</a>。高度需要设为 12em（因为 12 × 基准字号 10px = 120px），颜色需要使用 RGBA——即以 RGB (0,0,0) 表示的黑色，透明通道值约为 0.1–0.3。</dd>
<dt>“编写一个规则集，使 <code>&lt;h2&gt;</code> 的有效字号为 20px（但要用 em 表示），并设置合适的行高，把它放到页眉内容盒的中央……”（3 分）</dt>
<dd>正确的规则应<a href="style.css">类似这样</a>。高度需要设为 2em（2 × 10 = 20），行高最好设为 1.5（1.5 × 20px = 30px，即页眉内容的高度）。直接把行高设为 30px 也可以。</dd>
<dt>“编写一个规则集，使 <code>&lt;p&gt;</code> 的有效字号为 15px（但要用 em 表示），并设置合适的行高，把它放到页眉内容盒的中央……”（3 分）</dt>
<dd>正确的规则应<a href="style.css">类似这样</a>。高度需要设为 1.5em（1.5 × 10 = 15），行高最好设为 2（2 × 15px = 30px，即页眉内容的高度）。直接把行高设为 30px 也可以。</dd>
<dt>“最后一个细节：给 <code>&lt;article&gt;</code> 内的段落设置合适的内边距，使其左边缘与 <code>&lt;h2&gt;</code> 及页脚段落对齐，并把颜色设得较浅，以便于阅读。”（3 分）</dt>
<dd>正确的规则应<a href="style.css">类似这样</a>。内边距需要设为 1em，颜色需要设置为某种较浅的颜色，以便在之前设置的较深背景上清晰显示。纯白色就可以，或类似的颜色。</dd>
</dl>

## 其他值得思考的地方

<dl>
<dt>“如果你编写的 CSS 具有最佳可读性，每条声明单独占一行，可以获得加分。”（2 分）</dt>
<dd>如果 CSS 以可读的方式组织，每条声明单独占一行（或类似形式），即可得分；否则不得分。</dd>
<dt>“你所有规则的选择器链开头都应包含 <code>.card</code>，这样即使名片被放到包含大量其他内容的页面上，这些规则也不会干扰其他元素的样式。”（1 分）</dt>
<dd>这是测验中一个不错的补充，用来推广 CSS 的“隔离”（compartmentalisation）或“命名空间”（namespacing）思想，避免不同规则集相互干扰。在这个特定场景中并不算重要，但学生若能做到会很不错。</dd>
</dl>
