# 基础 HTML 文本评分指南

这些任务用于检验学习者是否理解 [HTML 文字基础](https://developer.mozilla.org/en-US/docs/Learn/HTML/Introduction_to_HTML/HTML_text_fundamentals)课程中介绍的 HTML 功能。该课程属于 MDN Web 开发学习区。

## 任务 1

本任务考查 HTML 标题和段落的理解。理想答案应类似于下面的代码：

```
<h1>基础 HTML 动物</h1>

<p>这是页面中的第一段文字，用于介绍这些动物。</p>

<h2>羊驼</h2>

<p>我们的羊驼非常喜欢列表项。它在网页上发现一片列表项时，就会像吃糖果一样把它们吃掉，同时舔着嘴唇。</p>

<h2>森蚺</h2>

<p>狡猾的森蚺喜欢在页面上滑行，并借助锚点快速穿行，悄悄接近猎物。</p>
```

子标题的层级不应高于顶级标题，段落也不应使用 &lt;p&gt; 以外的元素进行标记。

## 任务 2

任务 2 要求学习者使用 &lt;ul&gt; 元素包裹第一个列表，使用 &lt;ol&gt; 元素包裹第二个列表。两个列表中的每一项都需要使用 &lt;li&gt; 元素包裹。

完成后的代码应类似于下面的代码：

```
<h1>查看列表</h1>

<p>请将下面的我最喜欢的蔬菜列表转换为无序列表。</p>

<ul>
  <li>黄瓜</li>
  <li>西兰花</li>
  <li>芦笋</li>
  <li>甜椒</li>
</ul>

<p>请将下面的操作步骤转换为有序列表。</p>

<ol>
  <li>先敲门</li>
  <li>有人回应后，说出暗号</li>
  <li>至少等待 5 秒</li>
  <li>转动把手并推门</li>
</ol>
```

## 任务 3

最后一个任务用于检验对 &lt;strong&gt; 和 &lt;em&gt; 等基础行级元素的理解。学习者只需分别使用这些元素恰当地标记几个词语。

最终代码应类似于下面的代码：

```
<h1>强调和重要性</h1>

  <p>我在意两件事——<strong>音乐</strong>和<strong>朋友</strong>。有一天，我<em>或许</em>能让我的朋友彼此认识，也让他们<em>喜欢</em>我的音乐！</p>
```
