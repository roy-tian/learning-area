# 高级 HTML 文本评分指南

这些任务用于检验学习者是否理解 [高级文本格式化](https://developer.mozilla.org/en-US/docs/Learn/HTML/Introduction_to_HTML/Advanced_text_formatting)课程中介绍的 HTML 功能。该课程属于 MDN Web 开发学习区。

## 任务 1

本任务考查 HTML 描述列表的理解。理想答案应类似于下面的代码：

```
<h1>高级 HTML 动物</h1>

<dl>
  <dt>羊驼</dt>
  <dd>高大、毛茸茸的四足动物，耳朵尖。有时可以骑乘，但脾气暴躁，还会吐口水。非常喜欢列表项。</dd>
  <dt>森蚺</dt>
  <dd>一种体型非常大的蟒蛇；它会借助锚点快速穿行，悄悄接近猎物。</dd>
  <dt>嘻哈河马</dt>
  <dd>它的描述深不见底。</dd>
</dl>
```

## 任务 2

本任务用于检验对若干不太常见语义元素的理解。

完成后的代码应类似于下面的代码：

```
<h1>高级文本语义</h1>

<p>先从一段引用开始：</p>

<blockquote cite="https://developer.mozilla.org/en-US/docs/Learn/Accessibility"><p>默认情况下，只要使用正确，<abbr title="超文本标记语言（HyperText Markup Language）">HTML</abbr> 就具备可访问性。</p></blockquote>

<p><abbr title="层叠样式表（Cascading Style Sheets）">CSS</abbr> 也可以让网页更易访问，或者降低可访问性。</p>

<p>化学式：H<sub>2</sub>O（水）、C<sub>2</sub>H<sub>6</sub>O（乙醇）。</p>

<p>日期：<time datetime="2019-12-25">2019 年 12 月 25 日</time>（圣诞节）、<time datetime="2019-11-02">2019 年 11 月 2 日</time>（亡灵节）。</p>
```
